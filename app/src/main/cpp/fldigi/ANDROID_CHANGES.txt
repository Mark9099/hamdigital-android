  pskcoeff.cxx, pskvaricode.cxx       (src/psk)        - PSK filter coefficients, PSK varicode
  fftfilt.h, filters.h, complex.h, misc.h, gfft.h, pskcoeff.h, pskvaricode.h (src/include)
  config.h                            - an empty stand-in for fldigi's generated (autoconf) config.h

Receive-only editions (new files, fldigi's code with its algorithms unchanged):
  rtty_rx.h / rtty_rx.cxx   from src/cw_rtty/rtty.cxx + src/include/rtty.h:
    kept    - rx_init, restart (receive part, as set_params), mixer, reset_filters, decode_char, parity, baudot_dec
              (unshift-on-space on, fldigi's default), is_mark_space, is_mark, rx (the start / data / stop state
              machine, the CR-CR / LF-LF suppression), rx_process (the mark and space fftfilt RTTY filters, envelope and
              noise trackers, "optimal ATC" decision, AFC from the mark tone's phase at fldigi's slow AFC speed).
    removed - the user interface (scopes, viewers, status lines), progdefaults / progStatus settings (now set_params,
              set_freq, set_reverse, set_afc, set_squelch), Synop decoding, the signal search, FSK keying and transmit.
    changed - Metric(): fldigi measured the tones' power density on its waterfall; here the mark and space filters'
              envelopes against their noise floors give the s/n and the 0..100 metric (20 dB = 100). Decoded characters
              go into a string (take_text) instead of fldigi's put_rx_char.
  psk31_rx.h / psk31_rx.cxx from src/psk/psk.cxx + src/include/psk.h, BPSK31 only:
    kept    - the PSK31 set-up from psk::psk (PSKcore FIR pair decimating by 16, the Goertzel S/N-IMD filters),
              rx_init, rx_bit (PSK varicode), rx_symbol (BPSK path: phase decision, quality, DCD on the 0xAAAAAAAA
              preamble / off on six all-zero runs / else squelch), phaseafc, afc, signalquality, calcSN_IMD, rx_process
              (NCO mix, FIR filters, bitclk / syncbuf symbol timing).
    removed - the other PSK modes (PSK63..1000, QPSK, 8PSK, 16PSK, PSK-R, FEC, multi-carrier, vestigial carrier, OFDM),
              PSKmail, the user interface, settings (now set_freq, set_afc, set_squelch), the signal search (it used
              fldigi's waterfall) and transmit.
    changed - decoded characters go into a string (take_text) instead of put_rx_char.

Tested on the PC with generated signals (tools/test/test_fldigi.cxx): RTTY 45.45/170 copies fully to 0 dB SNR (2500 Hz)
and PSK31 to -5 dB, PSK31 nearly fully at -10 dB; both AFCs pull a few Hz of mistuning in.

0.13.0: PSK63 and PSK125. psk31_rx takes the speed (Psk31Rx(31 / 63 / 125)) with fldigi's own settings from
psk::psk() for MODE_PSK63 / MODE_PSK125: symbollen 128 / 64, dcdbits 64 / 128, and for PSK125 fldigi's SINC filter
pair (wsincfilt 1/symbollen and 1/16, FIRLEN taps) instead of PSK_CORE. Everything else is unchanged and the same at
every speed, as in fldigi: decimation to 16 samples a symbol, timing recovery, the S/N-IMD Goertzel bins. kb_tx's
psk31_tx_audio takes the speed too (symbol length; preamble and postamble of dcdbits symbols).
PC test (tools/test/test_fldigi.cxx, the app's transmitter into its receiver 3 Hz off): PSK31 copies fully to -7 dB SNR
(2500 Hz), PSK63 to -4 dB (one character wrong at -7), PSK125 to -4 dB.

0.14.0: Olivia.
  jalocha/pj_*.h   Pawel Jalocha's MFSK transmitter and receiver (fldigi src/include/jalocha, fldigi 4.1.23), unchanged.
  olivia_kb.h / olivia_kb.cxx  from src/olivia/olivia.cxx + src/include/olivia.h:
    kept    - restart() (tones, bandwidth, fldigi's default sync margin 8 and integration 4 FEC blocks, sample rate 8000,
              the first carrier from the centre: (f - fc_offset) / 500), rx_process (the squelch slider as the sync S/N
              threshold: s/5 + 3, 0 when off; unescape of 8-bit characters, fldigi's default; codes below 8 dropped;
              metric 5 x (sync S/N - 3)), rx_init, send_tones (the start / stop tones at the band edges, fldigi's
              raised-cosine shaping, TONE_DURATION 16 x 512 samples), tx_process (start tones, a leading NUL, the text a
              character at a time while the encoder wants more, Stop, run until not Running, stop tones, a block of
              silence).
    removed - the user interface, progdefaults / progStatus (now the constructor's tones / bandwidth, set_freq,
              set_squelch), reverse, the waterfall-based s/n, the 8-bit transmit escape (characters over 127 are sent as
              '.').
PC test (tools/test/test_fldigi.cxx, the app's transmitter into its receiver, noise in 2500 Hz, 10 s of noise after):
4/125, 8/250, 16/500 and 32/1000 copy the whole message to -13 dB SNR, 8/500 to -10 dB; tuned 20 Hz off it is found.
A minute of noise alone prints 54 characters with the squelch off, none at 5 and above (the page starts at 5). As in
fldigi, a few random characters can appear as a signal starts and ends.
